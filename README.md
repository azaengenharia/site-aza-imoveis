# Site AZA Imóveis

Site público estático para GitHub Pages com visual claro/dourado, lista de imóveis, filtros, destaques, galerias de fotos e vídeos e contatos dos corretores.

## Arquivos principais

- `index.html`: página pública.
- `data/properties.js`: imóveis exibidos no site.
- `css/styles.css`: identidade visual e responsivo.
- `js/main.js`: filtros, carrossel, galeria de mídia, renderização pública e botão do WhatsApp.
